# Student Grade Calculator

## Description

The Student Grade Calculator is a simple Python program that calculates the average percentage of five subject scores and displays the corresponding grade.

The program also finds the highest and lowest scores attained in the five subjects without using the built-in `min()` and `max()` functions.

It also displays a motivational message, the current date, and a thank-you message at the end.

## Features

- Takes marks for 5 subjects as input.
- Calculates the average percentage.
- Displays the student's grade.
- Finds the highest score without using `max()`.
- Finds the lowest score without using `min()`.
- Displays a random motivational message.
- Displays the current date.
- Uses a short delay before the final message.

## Grade Criteria

| Percentage | Grade |
|------------|-------|
| 90 - 100   | Grade A |
| 80 - 89    | Grade B |
| 70 - 79    | Grade C |
| 60 - 69    | Grade D |
| 50 - 59    | Grade E |
| Below 50   | Grade F - Fail |

## Requirements

- Python 3.x

The program uses the following built-in Python modules:

- `random`
- `datetime`
- `time`

No external libraries are required.
